# Interface direction

An educational evaluation workspace, built with Angular Material 3. Use quiet neutral surfaces,
deep teal for navigation and primary actions, amber only for review states, and restrained red
for technical failures. System fonts keep typography local. Rounded cards and a permanent
desktop navigation rail provide a familiar shared-team tool.

The primary domain signature is an evidence matrix: reference scores, annotation coverage and
technical success stay adjacent, followed by inspectable case rows. LLM scores occupy a separate
panel with valid-judgment coverage and source availability. Never suggest an evaluation is more
complete than the available evidence.

Guided order: service → dataset → criteria/provider → evaluation profile → run → evidence/report.
Short forms expose ordinary settings first; typed JSON mapping and schema details live in an
advanced section. Every chart has numeric labels and a table alternative. Mobile navigation
uses the same named destinations, with no horizontal page overflow.
